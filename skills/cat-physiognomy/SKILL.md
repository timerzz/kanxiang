# 猫相小笺

把用户的猫做成有梗又有依据的相猫海报：古籍相猫、现代通识与趣味脑洞三源混合，成品是 3:4 竖版做旧米黄纸撕纸海报。默认简体中文、温暖俏皮的语气。保留猫本来的长相，让特征与解读在画面上直接关联。除非用户只要文案或提示词，否则素材备好后直接生成，不额外索要批准。

## 路由请求

选择能满足请求的最小模式：

- **生成海报（默认）：**用户提供猫照并要求相猫、看相或海报时使用。完成辨识、选素材与文案后直接出图并检查，不额外索要批准。
- **只要文案或提示词：**仅在用户明确不要图片时使用，按其要求的形态交付纸片文案（按三源与去重规则编写）或一条可投产的生图提示词（按海报构图骨架）；不生成、也不暗示已生成成品图片。
- **无照片请求：**要求个体解读但没给照片时，先请用户上传猫照再开始；缺照片的纯脑洞、文案或雅号灵感请求按“只要文案”交付，并说明不以照片为据。
- 意图含糊但明确要求“做一张海报／看相出图”时，进入生成模式。同猫多照、多猫与合照的取舍见照片输入模式，不必为此停下来询问本 Skill 可以安全决定的选项。

## 加载相关参考

- **古籍候选：**先读 [相法速查](references/相法速查.md)。使用某条规则前，打开索引指向的书籍笔记对应章节，确认条件、措辞及来源层级。四份笔记是用户提供的书籍总结，不能称已核验原刻；一般无需联网，超出笔记的新引文或版本考证再查原始来源。
- **现代候选：**品种防盗扣标签、花色纹型、性格/爱好素材与脑洞触发，先读 [现代相猫速查](references/现代相猫速查.md)；其中的照片边界（血统、健康、易误读色）只作内部判断，不上画面。
- 生成前读 [海报构图](references/海报构图.md)，按其中的提示词骨架填入本次实际内容。古籍四书无需每张海报全部引用，回执只署实际采用的一两句来源。

## 照片输入与辨识

先逐张查看上传的照片；本地图片先用图片查看工具打开。文件缺失或无法读取时说明这一限制，而不是凭空编造分析。记录清楚可见的脸形、耳形、眼色、鼻梁、须形、花色、体态、四足、尾巴和姿势，同时标出遮挡、透视及光线的不确定。观察与解读分开：内部依据只取照片可见事实与用户提供的信息，视野外部位不补造；无需为了凑齐“十二要”要求补齐全部角度。海报文案可以写无依据的脑洞梗，但脑洞是玩笑不是观察记录，不混入品种与特征判断。

### 照片角色与处理

为每一张输入照片指定角色：

- **中央主体（编辑目标，高保真）：**同一只猫的多张照片选最清晰的一张。剪贴置中时保留脸形、眼色、花纹位置、毛长、姿势和可见范围；不因品种标签换成品种模板。
- **补证照片（参考）：**同一只猫的其余照片，只用于补证花纹、尾部、体态。用户提供的视频或习性描述可作“行为观察/用户告知”素材，只用确实可见或所述的内容。
- **合照成员／多猫：**多只猫默认每猫一张海报；用户指定合照时照办，防盗扣只给主角挂，部位标注的归属要清楚。只有归属不明且影响制作时才询问。

写文案前为每个主体准备简短内部对应表：部位或对象 → 可见事实或用户信息 → 素材源（古籍／现代／脑洞）与出处 → 纸片文案 → 画面锚点（锚定或自由）。

### 品种防盗扣标签

- 品种以防盗扣标签呈现：超市硬质防盗扣（半透明硬塑料扣夹、圆头磁扣、带一片小签）**穿过猫剪贴的纸面**——像真防盗扣穿过商品织物一样从纸张中穿过（纸面可见穿透孔或裂口），常取颈侧或肩背部，而不是贴在/压在猫身上。小签上直写品种中文市场通名——“银渐层”“蓝猫”“布偶”等，不加“外观似／疑似／仅凭照片推测”等任何限定。判据与边界见 [现代相猫速查](references/现代相猫速查.md)。
- 明显田园血统或特征不足以指向品种时，直写田园系通名（“田园·橘白”“狸花猫”等），同样不带限定语。用户提供的血统、领养记录或告知的品种可作标签依据，标签照旧只写通名。
- 多猫合照只给主角挂防盗扣；每猫一张的海报各挂各的。标签字属画面文字：黑体、短、逐字准确；与纸片一起参与全文去重（标签写了“银渐层”，纸片不再重复该品种名）。

## 选素材与写文案（三源）

1. 部位候选：按“加载相关参考”读速查文件。同一部位同一特征在多源同时命中时，只保留最有梗且照片可支持的一条，不固定“古籍优先”。
2. 三源内容：
   - **古籍条目：**相法速查与四书笔记中的部位、花色、雅号说法，可意译成现代白话梗，保留趣味。
   - **现代观察与通识：**品种性格刻板印象（通识梗，无个体预测力）、花色/体型民间印象（低优先，与古籍重合时择优）、照片可观察的姿态行为、用户告知的习性爱好。
   - **趣味脑洞：**由品种/花色/姿态/特征自由联想，可完全无依据，例如“前世可能是亚历山大三世的爱猫”“不是猫的话，可能有当宇航员的天赋”。
3. 默认构成：3–4 张锚定照片部位的纸片（短线或尖角指向，保留五官与关键花纹），可加 1–2 张自由脑洞纸片（无引线、落留白）；共 4–6 张，特写可 2–3 张。每张纸片都有实际文字，画面不出现空白或无字纸片，宁少一张不多一张。纸片不要求统一带标题或统一句式：古说引文、命理断语、口语点评、脑洞感叹交错使用，避免千篇一律的模板腔。文案是命理断语口吻——照片特征只作引子，落点是运势、福气、性格或际遇的判断（金眼可配“一岁就大富大贵，吃喝不愁”），可夸张、可无依据，说错了也没事；不写只复述照片外观的描述句（如“红脖一带，气场自来”），那不是相术。正文不用“；”（需要分层用换行、逗号或空格）；有标题时通常标题 2–6 字、正文 12–26 字，可加短口诀。宁换特征不重复、宁减文字不小字。
4. 语气与引用：温暖俏皮；只有确凿出自所读古籍原文的才加引号，自拟俏皮话与脑洞不加引号冒充古文。有明确出处的条目可加出处小注，格式“——《书名》”（如“——《相猫经》”）；现代通识梗与无依据脑洞不加出处，避免冒充研究或古籍。同一张海报上出处小注不重复同一书名——宁可只标一两处，也不要每条都注“——《相猫经》”；有据条目尽量分散到《猫苑》《猫乘》《衔蝉小录》等书，其余可不标、由回执汇总。
5. 不写清单：① 凶兆、败家、寿夭等负面古断整类跳过——不写也不做正向翻写；② 医疗、喂养、疫苗、品相鉴定类内容；③ 冒犯、低俗、人身向内容；④ “研究表明／科学证明／兽医专家说”等科学腔句式——脑洞以玩笑口吻写，不借科学外衣。
6. 画面不出现整行的来源或免责说明（含“古籍趣味解读，仅供娱乐”类字样），无依据内容不标出处；有明确出处的条目允许“——《书名》”式小注（见第 4 条），免责只在聊天回执出现。

## 生成与检查

1. 生成前重读 [海报构图](references/海报构图.md)，按骨架填写：参考图角色（逐张标记主体、同猫补证，多猫明确主角归属）、中央猫咪、防盗扣标签逐字、各纸片文字与锚点、禁止清单。
2. 使用可用的内置 image_gen 图像生成/编辑工具，把真实猫照实际作为参考传入，不只是文字描述；遵循当前工具的输入方式。所有目标图有本地路径时使用 referenced_image_paths，否则按工具支持的最近图片机制提供，两者不混用。无法包含所需参考图时请用户重新附图。
3. 猫以照片质感的撕纸剪贴置中偏上，保留脸形、眼色、花纹位置和主体照片姿势。要求宽:高 = 3:4，可在提示词中明确期望 1536×2048，不虚构工具参数。背景满幅做旧米黄旧纸，除纸面外无任何图形；画面无标题、无副标、无底部行；防盗扣从猫剪贴的纸面穿过（非贴在身上）且签文正确；全部文字（签与纸片）用现代黑体且都在撕纸体系内。
4. 检查成品：猫咪身份、逐字准确度、指向、撕纸材质、遮挡、比例，以及——无印章/古风字体/多余图形、无空白或无字纸片、无重复描述（含同义换写）、纸片正文无“；”、句式不雷同、无底部免责行、无禁写内容。有可读文件时读取实际像素核对 3:4，否则如实说明精确尺寸未验证。
5. 发现问题用图像工具定向修改，保留其余部分；最多自动修正两轮，仍有问题则明确说明，不称全部通过。

## 输出格式

展示图片并附简短说明，不展开内部对应表：

````markdown
**相猫海报**

![猫相小笺](本地成品文件路径或渲染图)

**说明**

- 主体照片：［哪一张／多猫合照的主角归属］
- 防盗扣标签：［直写的中文品种通名，如“银渐层”“田园·橘白”］
- 素材构成：［N 张部位纸片＋M 张脑洞纸片，纸片主题一句话］
- 古籍依据：［实际采用的古籍与章节一句；纯现代/脑洞可省略］
- 未验证或限制：［如精确尺寸未核对、被遮挡部位、修正轮次后仍存在的问题］
````

有本地成品文件时附可点击路径。海报为趣味娱乐内容，不承担品相、性格或健康结论——如需，免责一句只出现在本回执末尾，不上画面。用户只要文案或提示词时按“路由请求”交付，不展示伪成品。工具不可用时说明限制，交付已完成的文案与提示词，不称其为成品图片。

## 不可妥协的结果

一次成功的交付仍必须是一张保留本猫照片身份、宽高比 3:4 的做旧米黄纸撕纸海报：猫咪可辨认，防盗扣签文与纸片文字逐字正确，纸片指向与特征吻合，全文无重复描述，画面除纸面外无印章/古风字体/边框等任何附加物——而不是印章古风海报、按品种换脸的画像、重复描述堆砌或科学腔伪断言。内部要分清素材源：脑洞不冒充古籍引文或研究结论；负面古断、医疗喂养、冒犯内容与科学腔句式不上画面。

## 示例请求

- “给我家猫看看相，做张海报 [上传猫照]。” → 防盗扣标签 + 三源纸片。
- “这是同一只猫的三张照片，做一张相猫海报。” → 最清晰的一张居中，其余补证花纹、尾部、体态。
- “帮两只猫都看看相。” → 默认每猫一张海报。
- “把我家两只猫放进同一张合照海报。” → 合照模式，防盗扣只给主角挂，标注归属清楚。
- “它是领养的银渐层，特别爱钻箱子。” → 标签写“银渐层”，钻箱子习性入素材（环境丰容梗）。
- “先只要纸片文案，别出图。” ／ “给我一条可投产的生图提示词，不出图。”
- 可以接受完全无依据的脑洞，如“前世可能是亚历山大三世的爱猫”“不是猫的话可能有当宇航员的天赋”，但不得使用“研究表明/专家说”句式。
