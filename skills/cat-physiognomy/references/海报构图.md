# 3:4 撕纸相猫海报（视觉规范）

## 画面总览

- **画布**：竖版 3:4。
- **背景**：满幅做旧米黄旧纸肌理——暖米黄纸色、纸纤维、斑驳、轻微扫印、哑光吸墨。这是唯一背景：无边框、无样机、无印章、无祥云/水墨/卷轴/贴纸花边等一切附加图形。
- **无文字标题**：画面没有标题、没有品种副标、没有底部说明行（无来源行、无“仅供娱乐”行）。
- **中央主体**：猫的照片质感撕纸剪贴，约画面宽度一半至三分之二，居中偏上，按姿势调整；纸边自然不规则撕裂、带纸纤维与轻柔投影。保留脸形、眼色、花纹位置、毛长与姿势；不插图化、不换成品种模板。
- **防盗扣标签**：超市硬质防盗扣造型——半透明硬塑料扣夹、圆头磁扣、扣身带一片小签；像真防盗扣穿过商品一样**穿过猫剪贴的纸面**（纸面可见穿透孔或裂口），常取颈侧或肩背部，而不是贴在/压在猫身上。小签上只有品种名，直写中文市场通名（“银渐层”“蓝猫”“田园·橘白”等），现代黑体、逐字准确。多猫合照只给主角挂。
- **撕纸纸片**：全部可见文字（防盗扣签 + 纸片）都走撕纸体系。纸片为不规则撕纸对话框，纸边各异、文字底色干净（米白/白），短线或尖角指向对应部位，引线端点明确、不交叉、不穿过双眼。字体统一现代黑体（无衬线），不用书法/篆隶/行草/古风字体。每张纸片都有实际文字，不出现空白或无字纸片；纸片正文不用“；”（分层用换行、逗号或空格）；句式长短口吻交错，避免每张同款模板。
- **配色**：米黄纸底 + 暖灰/棕黑字为主；极少量低饱和点缀可用；不用大红印章感色块。
- **数量**：3–4 张部位纸片 + 可加 1–2 张自由脑洞纸片（无引线、落留白），共 4–6 张；特写可 2–3 张。宁可减文字，也不缩成看不清的小字。保留约 5% 安全边距。
- **色彩/文字干净**：纸片底色干净，文字底色不喧宾夺主。

## 去重纪律（生成时逐项核对）

- 同一特征或同义描述在整个画面只出现一次：防盗扣标签 + 全部纸片合计（“耳小而灵”出现一次后，任何纸片不再写第二遍同义句）。
- 同一部位只给一张纸片；古籍雅号、现代花色名、脑洞指向同一特征时只保留最有梗且照片可支持的一条。
- 标签写了品种名（如“银渐层”）后，纸片不再重复该品种名，改从别的角度（特征、姿态、脑洞）写。

## 文案要求

- 部位纸片：不要求统一带标题；有标题时标题 2–6 字、正文 12–26 字为宜，可加短口诀。描述句、古说引文、口语点评、脑洞感叹交错，句式不雷同。
- 出处小注：有明确出处的条目可在末尾加“——《书名》”（如“——《相猫经》”）；现代通识梗与无依据脑洞不加。
- 自由脑洞纸片：无依据的玩笑话（“前世可能是亚历山大三世的爱猫”），禁“研究表明/科学证明/专家说”句式。
- 不写：凶兆/败家/寿夭类负面古断、医疗/喂养/疫苗类内容、冒犯/低俗内容。
- 纸片正文不用“；”；只确凿出自所读古籍原文的才加引号；自拟与脑洞不加引号。

## 定向修正

- 出现空白/无字纸片：删除该片或补上实际文字。
- 防盗扣贴在/压在猫身上：重申“从纸面穿过、纸面可见穿透孔”。
- 纸片正文出现分号或句式雷同：重写对应纸片，换句式。
- 出现印章/古风字体/多余图形：重申“米黄纸是唯一背景、无任何附加图形、全文字现代黑体”，只改该处。
- 文字重复或过密：删同义条目或换特征重写该纸片。
- 防盗扣变形、签文错字：只改该处，重申防盗扣造型与逐字文字。
- 锚点错位：只改纸片与引线位置。
- 身份漂移：重申主体照片与关键花纹，继续传入原始猫照。
- 比例错误：要求图像工具调整到 3:4，保持猫与文字完整，不裁掉纸片换比例。
