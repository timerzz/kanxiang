# 《猫乘》（清·王初桐辑）

> 本文只整理《猫乘》所保存的历史材料，不把书中的占验、传说、志怪或古代医方当作现代动物学、医学事实。引文均为《猫乘》条目中的短句；条目往往是王初桐转引更早典籍，已尽量注明原书与《猫乘》卷次。

## 一、书目信息与版本

- **书名、作者**：王初桐（清）辑《猫乘》，八卷。王初桐《猫乘小引》署“嘉庆三年冬日”（嘉庆三年，1798）。
- **编纂性质**：作者说经史所见猫事很少，其余“杂出于传记百家之书”，在校书之余指授抄胥采录，随后“削繁去冗，分门析类，厘为八卷”。因此它是猫事的**类书式资料汇编**，不是一部连续叙述的博物志，也不是王初桐亲自观察所得的实验记录。
- **卷目与大致内容**（以中国哲学书电子化计划所载文本为准）：
  - 卷一：字说、名号、呼唤、孕育、形体。
  - 卷二：事；后段又见形体及医药材料。网络转录中卷一、卷二的形体及本草条目有重复，不能据此推断为新的品种系统。
  - 卷三：畜养、调治、瘗埋、迎祭。
  - 卷四：捕、相乳、义、报、言、化、鬼、魈、精、怪、仙。
  - 卷五：种类（家猫、狮猫、野猫、狸、灵猫、玉面狸、风狸等相涉名物）。
  - 卷六：杂缀、图画（也包括以“猫”为名的器物、植物、地名、戏曲等）。
  - 卷七：文（如韩愈《猫相乳说》、杨夔《蓄猫说》、薛瑄《猫说》等）。
  - 卷八：诗、词、句。
- **底本与数字版本**：中国哲学书电子化计划说明其电子文本以馆藏影像为底本，做过 OCR_MATCH、标注和标点；图书馆页说明原书“有些字迹不清、有些页残”，原书来源为北京大学图书馆，扫描者为 CADAL。遇到 OCR 缺字或残页，以下不补写臆测内容。

## 二、内容总览：王初桐怎样编排“猫事”

《猫乘》把猫放在多种知识框架中：字书训诂和别名、农事和礼仪、家居饲养、捕鼠效能、异闻报应、绘画题咏以及以猫作譬喻的文章。卷一至卷五较接近“形名—生活—类别”的材料；卷七、卷八则保存了大量以猫说人、借猫讽世的文学文本。书中“猫”有时是家养捕鼠动物，有时是“狸”及南方山林兽类，有时只是器物、植物、地名或比喻，不能将全书的“猫”都视为同一生物分类。

## 三、名称、品类与毛色形态

### 3.1 家猫的名称和俗称

卷一“名号”汇集：狸、家狸、女奴、乌圆（或作蒙贵/蒙员）、狸狌、狸奴、狻猊等名称；卷一还载“红叱拨”（《酉阳杂俎》说为灵武所产猫名），以及个人给猫取的“白老”“雪姑”“虎儵”等名字。卷三、卷八的材料又见“銜蝉”“粉鼻”“雪儿”等家猫名。名称有时是文学雅称或宠物名，不能据名直接反推品种。

### 3.2 家猫的毛色、产地与用途

- 《埤雅》（卷一“形体”）称猫有“黄、黑、白、驳”数色；《便民图相猫法》（同条）特别说纯白、纯黑、纯黄者“不须拣”，花猫则看身、四足及尾的花纹是否相连。这是历史上的相猫说法，不是现代遗传分类。
- 卷五“种类”记海州猫被称为天下第一；楚州射阳有所谓褐花色，灵武有所谓青骢色。这些是地域名物记录，书中没有足够材料证明它们是稳定的现代品种。
- “狮猫”在《一统志》《事物紺珠》《咸淳临安志》等材料中被描述为暹罗所产、身大长毛、蓬尾，或“长毛白色”。《咸淳临安志》明确说这类猫“**不捕**”，主要以观赏而受贵爱，显示“捕鼠猫”和“观赏猫”的评价标准可以不同。
- 卷五又把“野猫”、猫狸、虎狸、九节狸、灵猫（香狸）、玉面狸（牛尾狸、果狸）、风狸等并列收入。书中引《正字通》《本草纲目》等，往往按外形、产地、食性或药用分辨；《天香楼偶得》还明确提出“蒙贵非猫也”，说明古籍之间存在名物混淆。它们可能涉及狸、灵猫科或传说动物，不宜统称为家猫品种。
- 卷五所载“猫王”故事称西番贡猫能使数十鼠伏死；卷五又录孙三把红色猫染成异色高价出售，半月后褪成白猫。这些分别是异闻和骗术故事，不是品种性能或毛色遗传的证据。

### 3.3 形态与“优劣”说法

- 《埤雅》（卷一“形体”）说猫“狸身而虎面，柔毛而利齿”，并以“尾长、腰短、目如金银、上颚多棱”为良。
- 《便民图相猫法》（卷一“形体”）以身短、长尾、金银眼、虎威面、声响亮为佳；露爪、耳薄、面长、尾大等另有吉凶或功能判断。所谓口内“三坎、五坎、七坎、九坎”分别对应能捕鼠一至四季，也是相猫术的经验化表达，不是经过验证的性能指标。
- 卷一、卷二的多条材料说猫眼瞳孔随时辰呈线、圆或枣核形，又说番猫有金眼、银眼或一金一银；卷六“图画”还保存了对画猫辨午时的争论。《广川画跋》质疑画中把猫睛画成竖线的说法，认为“于猫睛中不能为竖线”——这至少提醒读者：书中并非所有引述都得到一致认可。
- 《尔雅翼》（卷二“形体”）说猫捕鼠后耳朵会留下“如锯”的缺口；《宣和画谱》则概括猫似虎而耳大、眼黄。这些是古代观察或比类文字，应和“相猫法”的优劣断语分开。

## 四、性格、气质与行为说法

- **驯顺、亲人和守主**：卷二《夷坚志》故事写山庵的猫“极驯”，白天在僧身旁，夜宿床下；卷三《南部新书》写张大夫饲养众色猫，退朝时猫群“曳尾延颈”迎接；卷三《七修类稿》写寺猫认得主人声音，主人敲门才衔钥匙出来。它们是故事中的个案，不是猫必然能识人或传递物品的结论。
- **亲热、好睡和取暖**：卷二《义山杂纂》仅说“猫暖处便在”；卷八诗歌常写猫卧花阴、氍毹、炉边和主人床席。文学材料可反映人与猫共居的想象和生活经验，但不等于行为学统计。
- **警觉、善捕与“静”**：卷四《陈止斋集》说“猫之善捕鼠者，日常睡；终日跳掷者，必不”。它把伏伺与捕鼠能力相联系；卷七舒元舆《养狸述》则写狸闻鼠气便凝蹲、跃起搏鼠。这类叙述具体描写了伏击式捕猎，但仍是古人文字记录。
- **野性和难驯**：卷五《事物紺珠》说野猫“亦入人家，但难驯”；卷七杨夔《蓄猫说》写为捕鼠而取野狸之子，虽厚养仍“常思逸于外”。这与家猫亲人故事形成对照，但“野猫”一词的古今含义并不固定。
- **食性和玩耍**：卷三列鱼、鳅为家猫日常供食，记猫食薄荷“即醉”（《埤雅》）；也记猫食鱼、鸡、虫是“性之所耽”。卷二、卷七、卷八大量故事和诗写猫捕鸡、鸟、燕、雀，说明古人知道猫的捕食对象不只鼠；并不能把“猫只为捕鼠”当作自然事实。
- **母性、互乳和忠义**：卷四“相乳”及卷七韩愈《猫相乳说》记母猫把无母小猫衔到另一窝共同哺乳；卷四“义”记家猫认主、远返或救主，卷八也有“水中得弃猫，拯救久之乃复活”的诗题叙事。互乳可能是观察记录，远返、投水等属于故事传统；书中常进一步把动物行为解释成仁义和政治祥瑞，这属于当时的道德寓言。
- **攻击性及失职**：卷二《朝野僉载》写猫饥饿时咬杀同器的鹦鹉；卷七薛瑄《猫说》写一只大猫不捕鼠却反复咬鸡，主人斥为“舍其病，犹可用其能”，最后发现它连捕鼠能力也没有。卷七、卷八常以“猫失职”讽刺尸位、姑息或贪暴的人，这些是伦理比喻。

## 五、习性、捕鼠功能和日常生活

### 5.1 捕鼠

《礼记·郊特牲》是《猫乘》反复引据的早期礼制材料，理由是“迎猫，为其食田鼠也”（卷三“迎祭”）。《庄子》《尹文子》等则以狸狌的敏捷对比良马、牛捕鼠的无能（卷四“捕”）。王守仁一条疏文说猫击鼠“**不穷其伏，而但乘其出**”（卷八“句”），说明古人观察到猫守候鼠出穴的策略。

卷四还保存“蠶猫”（养猫驱鼠以护蚕）、梦见猫捕鼠主得财、以及苏轼“养猫以捕鼠，不可以无鼠而养不捕之猫”的政论化引申。卷七、卷八的文章把“有职而不举”与不捕鼠的猫相连；这反映的是人对家猫实用功能的期待，并非所有猫的个体能力都相同。

### 5.2 饲养、食物、训练与处置

- **获得**：卷三《茶烟阁体物集》记吴俗以盐换猫；卷八诗歌也反复写“裹盐”聘猫、“买鱼”酬猫。卷七《本猫说》则主张在狸乳育时取子，长成后捕鼠；卷七《养狸述》写闭门塞穴、放狸入室观察并持续驯饲。
- **喂食和器具**：卷三《梦粱录》说养猫之家每日有人供鱼鳅；卷三、卷五记以鱼、猪肝等喂猫，明代内官甚至用铜制猫食盆。卷三《王铚杂纂续》有“邻舍猫，爱便宜，养雌猫”的戏谑，不能当成饲养原则。
- **调治**：卷三“调治”记六月六日浴猫犬、猫病灌乌药水、猫生虱用桃叶或楝树根擦等。卷一、卷二还收录大量猫头、皮毛、尿、粪、肝等入药的古方。这些只证明相关医药观念曾被抄录；没有现代临床证据，且可能有卫生和毒性风险，不应照方施用。
- **繁育**：卷一“孕育”转录“猫两月而生，一乳数子”等说法，也收录以斗、扫帚、灶神祈求受孕的民俗，以及“春生者佳”的占验。生殖周期和民俗祈求须分开；后者不是生物学方法。
- **绝育和安葬**：卷二末引《臞仙肘后经》“净猫，如阉猪鐓鸡”，但不提供现代意义的操作方法；卷三“瘗埋”记死猫挂树、埋猫引竹等民俗，又记为宠猫造棺、建道场。均应视为历史习俗或故事。

## 六、面部、眼睛、体态及相猫/选猫方法

《猫乘》没有一套由王初桐独创的统一标准，而是并列保存多种相猫法：

1. **体型和毛色**：《埤雅》及《便民图相猫法》偏好身短、腰短、尾长、柔毛利齿；纯白、纯黑、纯黄据说可不挑，花猫则要看四足和尾部花纹是否相连。
2. **眼睛**：以金银色、明亮为佳；又把瞳孔形状和时辰相配，甚至把猫睛作为“定时”之物。卷六绘画评论指出这种说法在画面表现上存在争议；不可把它当作精密时钟或品种鉴定。
3. **面、口、耳**：面似虎、声音响亮、上颚棱数多被列为优点；长面、薄耳、花朝口（《便民图相猫法》术语）被附会为不同后果。所谓口中坎数与捕鼠季数的对应，属于相术经验或民间口诀。
4. **功能试验**：比起外貌，卷四《陈止斋集》及卷七诸文更看重实际捕鼠；薛瑄《猫说》提醒“体魁爪利”也可能只会咬鸡。若从史料中提炼出较可靠的历史判断，只能说古人也注意到外形并不能保证工作表现。
5. **选猫与野性**：卷七《养狸述》《本猫说》强调从幼猫、乳期取养并训练；卷五说野猫难驯。二者是不同语境下的训养叙事，不可直接转化为现代购买或繁育建议。

## 八、哪些是早期典籍，哪些是王初桐辑录/按语

- **早期典籍的引文**：绝大多数条目以《礼记》《尔雅》《庄子》《酉阳杂俎》《埤雅》《本草纲目》《夷坚志》《五灯会元》等书名开头，随后是所引的原文或转述。它们的时代从先秦至明清不等，不能合并成同一时代的“古人观点”。
- **王初桐的编纂层**：王初桐在序中说明自己负责采录、删繁、分门、分类；卷中“又”“按”、异文并列和跨书合录，体现辑者编排。序末说“不关大道，亦著略家所不废”，并否认专以讥世为作，说明书的定位是博闻杂录，偶有自伤自悔的语气。
- **按语与转引的区别**：如卷三引《雪涛谈丛》并附张宗圣解释“猫来孝家”实为“耗”之讹，这是《雪涛谈丛》中的按解，不是王初桐的现代判断；卷一“形体”把《埤雅》《广西通志》《便民图相猫法》《挥麈新谈》连列，是不同来源的并置，也不代表王初桐为各说背书。
- **卷七、卷八的文学层**：韩愈、杨夔、舒元舆、薛瑄等文章及诗词，是王初桐辑入的历史文学作品；其中把猫鼠行为比作政治、仁义、官职的部分，应按寓言、讽喻和诗歌阅读。

## 九、史料性质、可靠性与局限

1. **汇编而非实证调查**：条目大多是转引，来源之间可能互相抄撮；故事只说明“某书曾如此记载”，不能证明事件确实发生。
2. **类别不可直接对应现代分类**：古人“猫、狸、野猫、蒙贵、灵猫、风狸”等名称存在时代、地域和书籍差异；其中一些可能是不同动物，另一些带有传说色彩。不要把“狮猫”“海州猫”等自动转换为现代品种名。
3. **相猫法是历史观念**：体型、眼色、口中坎数、花纹等“良”“劣”判断没有现代控制实验支持；即使部分描述来自经验，也不能推出个体捕鼠能力。
4. **志怪、祥瑞、报应须单列**：卷四“鬼、魈、精、怪、仙”、猫鼠同乳为祥瑞、猫能变龙或化妇人等，属于宗教、志怪、政治象征或报应叙事，不是动物生理事实。书中“猫鼠同乳”虽有多种转引，仍不能据此概括为常态。
5. **医药材料不可照用**：猫肉、头、骨、毛、尿、粪等古方只可作为医学史材料；古代“治某病”的说法缺乏现代安全性、有效性验证，且可能涉及感染、毒性和虐待风险。
6. **底本和转录有缺损**：馆藏说明原书有字迹不清和残页；电子文本中可见“×”等无法辨识字，卷一“志奇”条还标出疑有缺页。本文不据残缺处补足原文，引用也避开不确定字句。不同影印本、OCR 和古籍整理本之间可能有异文，正式校勘应回看原页。
7. **重复与异文**：在线章节中卷二后段与卷一形体、本草条目有显著重复，且同一故事常注明“又见某书”或有文字差异。主题归纳以可读条目为限，不把重复计作不同观察样本。
