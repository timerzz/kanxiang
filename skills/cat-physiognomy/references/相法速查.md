# 相法速查

从用户提供的四份总结提炼，用于选择候选；引用前读链接章节。现代趣味改写与古籍短引分开。

## 部位

下列主要见 [《相猫经》第五节“十二要”](相猫经.md)，署名“《猫苑》所录《相猫经》”。

| 部位 | 可见条件与可用依据 | 使用边界 |
|---|---|---|
| 头面 | 清楚的圆润轮廓；“头面贵圆” | 圆脸不直接等于英短或亲人 |
| 眼睛 | 色彩可信的金眸；“金眼夜明灯” | 金银眼不必然异瞳；闭眼不用 |
| 耳朵 | 相对头部显小；“耳贵小贵薄” | 只谈小耳；薄度、耐寒不由照片断定 |
| 鼻梁 | 侧面可见平直轮廓；“鼻贵平直” | 鼻湿干不从高光推断 |
| 须 | 清晰可见挺立舒展；“须劲虎威多” | 只借虎威意象，照片不能证实硬度 |
| 腰身 | 姿势与透视允许判断短腰；“腰贵短” | 毛蓬松、蜷卧不能证明腰短 |
| 后脚 | 全身站姿可比较前后足；“后脚贵高” | 单条件不推出整句威豪、捕鼠判断 |
| 爪 | 爪部清晰且爪尖收起；“爪贵藏” | 当时藏爪不等于性格温顺；油爪另有按语 |
| 尾 | 全尾可见且长细尖；“尾贵长细尖” | 尾节短与常摆无法由静照确认，不套整条“尾长节短多伶俐” |
| 睡姿 | 确见蜷圆、藏头；“睡要蟠而圆” | 只说可见姿态，不补尾动或日常习惯 |

叫声、上腭坎数不作为普通猫照的默认项目；无需让用户操作猫去验证。用户主动提供音视频时仅按确实可听见、看见的内容扩展。

## 花色雅号

使用前读 [《相猫经》第六节](相猫经.md)，必要时用 [《猫苑》毛色部分](猫苑.md) 核对层级。命名条件所需区域必须可见；局部像但缺少尾部、腹部等证据时只描述花色或说明近似。

| 名称 | 条件 |
|---|---|
| 乌云盖雪 | 背黑，腹、腿、蹄爪白 |
| 踏雪寻梅 | 黑色主体仅四蹄白，与白腹白腿区分 |
| 雪里拖枪 | 通身白，尾独黑 |
| 挂印拖枪／印星 | 白身黑尾，额上一团黑 |
| 垂珠 | 通身黑，尾尖一点白 |
| 银枪插铁瓶 | 黑身白尾 |
| 金簪插银瓶 | 白身黄尾 |
| 金被银床 | 黄身白腹 |
| 绣虎 | 白身黄点 |
| 梅花豹 | 黑身白点 |
| 将军挂印 | 通身黑或白，背上一点黄毛 |

纯黄“金丝”、纯黑“铁色”属于黄汉按语，不写成《相猫经》原句。卷下丁仲文还列出纯黄金丝虎、戛金钟、大滴金，纯白尺玉、宵飞练，纯黑乌云豹、啸铁，花斑吼彩霞、滚地锦、跃玳、草上霜、雪地金钱，狸驳雪地麻、笋斑、黄粉、麻青；这些是雅号库，原文没有逐一给出可从照片反推的细部条件。郑荻畴《猫格》的小山君、鸣玉侯、锦带君、铁衣将军、麴尘郎、金眼都尉、雪氅仙官、丹霞子、鼾灯佛、玉佛奴也只作标题灵感，不绑定外形。古书玳瑁有三色语境，与现代花色用语区分。不强配雅号；狸花、橘白等可直接描述。

## 现代品种与相猫分栏

现代品种判断只写外观概率，不代替血统证明。将“外观似现代品种”和“古籍相猫观察”分开：

| 现代品种线索 | 可并列的古籍观察 | 组合方式 |
|---|---|---|
| 英国短毛猫常见圆脸、相对小耳、短厚体态 | “头面贵圆”“耳贵小”；体态要有清楚站姿才谈腰身 | 品种栏写“外观似英国短毛猫”；相猫栏逐项写照片看见的圆脸、小耳，不能把英短血统当作已证实 |
| 暹罗猫常见重点色、较大耳、修长体态 | 眼色或面部轮廓可另做相猫观察 | 不因“大耳、长身”不合某些古法标准而否定现代品种；重点色也不强配古代黑白雅号 |
| 波斯猫常见长毛、短鼻、圆脸 | 圆脸可对应“头面贵圆” | 短鼻是现代品种外观，不能套“鼻贵平直”来判品种优劣或健康 |
| 无毛猫、卷耳、折耳等特殊品种外观 | 只有实际可见的眼、脸、耳、姿态可做古籍趣味标注 | 不用古籍缺少的毛色或耳形标准否定品种，也不把遗传特征直接写成性格、健康或命运 |

照片无法稳定区分现代品种时，使用“外观似……／可能为……／家猫混种，具体品种未确定”。用户提供血统、领养记录或注册信息时，将其标注为用户提供的信息，与照片推测分开。

- [《相猫经》](相猫经.md)：第五、六节是部位及毛色主入口，第七节区分后出的验猫法。
- [《猫苑》](猫苑.md)：核对口诀、黄汉按语及异说；需要五长五秃、拦截纹、寿纹、花朝口、卷下雅号、行为反例及来源冲突时查阅，古名不能直接映射现代品种。
- [《猫乘》](猫乘.md)：第三、六节补充形态相法；“猫儿身短最为良，眼用金银，尾用长”标为卷一“形体”引《便民图相猫法》。需要闲卧气氛或诗意时查第四、七节，不把故事写成个体规则。
- [《衔蝉小录》](衔蝉小录.md)：需要标题、雅称、聘猫典故、诗词时查卷一、二、七；卷二“眼要金光”“面要虎威”“声要喊”为转引相法。诗意雅称不是照片识别出的品种。
