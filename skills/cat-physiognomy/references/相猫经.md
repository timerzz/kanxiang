# 《相猫经》

> **阅读提示**：本文所说的“《相猫经》”不是把《猫苑》全书当作一部同名古书。现今可核对的《相猫经》文字，主要见于清代黄汉辑《猫苑》“形相”“毛色”两门；本书原口诀统一标作“《猫苑》所录《相猫经》”。《猫苑》中的“汉按”、友朋说、地方传闻，另行标明，不能冒充《相猫经》原文。下文的“贵、凶、吉、主富贵”等是传统相法判断，不是现代生物学或行为科学结论。

## 一、书目信息、作者与版本边界

- **现存可见载体**：清黄汉辑《猫苑》卷上“形相”“毛色”条。CText 的书名栏署“猫苑 清 黄汉辑”；黄汉自序署“咸丰壬子”（1852），卷首另有序署咸丰三年（1853）。因此可以较有把握地说，今天可见的辑录形成于清代咸丰年间。
- **《相猫经》的作者、年代**：现有可核对材料没有给出作者姓名、时代或独立传记，不能据“相猫经”三字擅定作者、朝代。黄汉在《猫苑》凡例说“猫事本无专书，古今典故仅散见于群籍”，说明他所面对的是散见材料；在“形相”开头又说“猫之相有十二要，皆出《相猫经》，兹备录之”。这只能证明黄汉把一组相猫口诀归名为《相猫经》，不能证明原书作者。
- **是否独立成书**：目前可核实的文本中，未见可确认的《相猫经》单行刻本、刊年或卷数。故宜表述为：**《相猫经》的单刻本今未见（可谨慎说失传或至少未见存本），现存文字主要通过黄汉《猫苑》的后世辑录保存**。这不是断定历史上绝无单刻本；只是现有材料不足以重建原书。
- **本文采用的版本层级**：第一层是《猫苑》明确标作“相猫经”的句子；第二层是黄汉的“汉按”、友人说及所引其他书。这两层必须分开。比如“惟提耳而四脚与尾随即缩上为优”是《猫苑》后出的按语所记粤人验法，并非十二要的原句。

## 二、内容总览：一部以外形推断捕鼠效能的相法口诀

《猫苑》把《相猫经》概括为“十二要”，按头面、耳、眼、鼻、须、腰、后脚、爪、尾、声、口腔、睡姿观察。它还记录毛色纯杂、斑纹、尾色等“品相”，并把某些外形同“伶俐、威猛、懒、寿夭、捕鼠强弱、会否扰鸡鸭”等联系起来。

这套文本的核心用途不是建立现代意义上的品种分类，而是为养猫、买猫、纳猫者提供一套传统经验与占验混合的识别语言：理想猫多被设想为能镇鼠、少扰家禽、灵活有威、可守家；“贵、富、豪杰”等又把猫的品相投射到主人的命运。这些“对应”是文献所记的传统说法，不能当作经过控制实验验证的预测。

## 三、品种／类别：不是现代品种学

《相猫经》本身重点在“相”（形态及其吉凶），没有现代育种学意义上的品种标准。按《猫苑》所录，可整理为下列**传统类别和毛色称谓**：

1. **纯色类**：纯黄、纯白、纯黑，以及“纯狸色”（狸色大致指虎斑、杂色一类的传统称呼）。原文以“色之纯”为可贵依据，次序说纯黄最上、纯白次之、纯黑又次之；这是一套审美和相法等级，不是遗传学等级。
2. **驳色、斑色类**：乌云盖雪、玳瑁斑、狸而驳；三色猫又称玳瑁猫。黄汉按语说纯黄“金丝”、纯黑“铁色”，并附会雌雄，但这属于《猫苑》按语，不能倒装成《相猫经》正文。
3. **特殊尾色、额色类**：纯白黑尾称“雪里拖枪”；白身黑尾而额有黑团称“挂印拖枪”或“印星猫”；黑白尾称“银枪插铁瓶”；白身黄尾称“金簪插银瓶”；通身黑而尾尖一点白称“垂珠”。这些是纹色名称，不是可与现代品种一一对应的名称。
4. **杂类名称的文献背景**：《猫苑》“种类”门还列狮猫、无尾猫、四耳猫、麒麟尾（歧尾）猫等地方或异相称谓；有的条目明确说产地、传闻和捕鼠能力不同。例如“无尾猫”是《猫苑》友人说的外来猫称谓，不能据此直接等同于今日某一确定品种；“狮猫”也只是清代文本中的名称。

因此，阅读“品种/类别”时，应把“金丝、印星、乌云盖雪”等当作历史上的外观命名和选猫语汇，而不是现代猫种登记。

## 四、性格、气质与习性说法

### 4.1 《相猫经》直接关联的气质词

- “须劲虎威多”：硬直的须被解释为有“虎威”。
- “尾长节短多伶俐”：尾形被联系到灵巧、伶俐。
- “尾大懒如蛇”：大尾被联系到懒惰。
- “眼带金光身要短，面要虎威声要喊”：金光眼、短身、虎威面、洪喊声共同构成勇猛相。
- “坐立尾常摆，虽睡鼠亦亡”：尾部常摆被联系到即使睡着也能捕鼠，重心仍是捕鼠功能。
- “身屈神固，一枪自护”：蜷曲、神定的睡姿被解释为自卫有力。

这些不是性格测量，而是把可见外形拟人化、虎化，再推到“勇、灵、懒”等性状。

### 4.2 《猫苑》另条记载的习性（不是《相猫经》原文）

黄汉在《猫苑》其他门类中还记录猫“禀性乖觉，气机灵捷”、衔蝉扑蝶、捕鼠、闲卧等，是黄汉自序对猫的概括；《猫苑》又收录传闻称有的猫“雄桀不驯”、有的“和柔善媚”、有的“散逸喜走”、有的“依守不离”。这些材料可用于了解清人如何谈猫的气质，但应标为《猫苑》编者或后出记闻，不能改写成《相猫经》十二要。

## 五、十二要：逐项规则、口诀与夹注

本节据[识典古籍《猫苑》卷上“形相”](https://www.shidianguji.com/zh/book/CADAL02035808/chapter/1l7l4yva9iyhy)“猫之相有十二要”至“毛色”前核对，连同夹注读取。下列为通行简体转写；“经云／又云”与“汉按／友人说”分栏，不把后者算作原口诀。表内吉凶、贵贱和能力判断均为历史说法。

| 项目 | 主规则及所引口诀 | 对应意义与补充层级 |
|---|---|---|
| 1 头面 | 头面贵圆；“面长鸡种绝” | 圆面为佳；长面与危害鸡群相连。不能由此诊断某只猫的行为。 |
| 2 耳与胸部组合 | 耳贵小、贵薄；“耳薄毛毡不畏寒”；“耳小头圆尾又尖，胸膛无旋值千钱” | 小耳、圆头、尖尾、胸无旋是组合佳相，不只是一条耳相。识典字形为“毛氊”，旧笔记“毛繵”改正。随后《蠕范》《花镜》畏寒与饲养材料是插入引书。 |
| 3 眼 | 眼贵金银色，忌黑痕入眼、泪湿；“金眼夜明灯”；“眼常带泪惹灾星”；“乌龙入眼懒如蛇” | 金银色为赏，黑痕、带泪为忌；未要求必须异瞳。黄汉按语说自己养过“乌龙入眼”而十分勤捷的猫，反驳“皆懒”，但仍附会遭凶。人有猫眼“近贵隐富”来自《神相全编》，是人相，不是猫相。 |
| 4 鼻及面部组合 | 鼻贵平直、宜干，忌钩与高耸；“面长鼻梁钩，鸡鸭一网收”；“鼻梁高耸断鸡种，一画横生面上凶。头尾欹斜兼嘴秃，食鸡食鸭卷如风” | 包括钩鼻、高鼻梁、面上一横纹、头尾歪斜及嘴秃等条件，传统断为侵食鸡鸭或凶。夹注解释“嘴秃”为“无须”，不能改成秃毛嘴或残缺嘴。“一画”不能与另一来源的“顶下拦截纹”混同。 |
| 5 须 | 须贵硬，不宜黑白兼色；“须劲虎威多”；“猫儿黑白须，屙屎满神炉” | 硬须联系虎威；黑白兼须联系排泄禁忌。旧总结把“屎”写成“尿”，据此本订正；不能把照片中的舒展须直接判断为硬须。 |
| 6 腰 | 腰贵短；“腰长会过家” | 短腰佳，长腰被联系到过家、离家；具体语义不扩大为确定性格。 |
| 7 后脚 | 后脚贵高；“尾小后脚高，金褐最威豪” | 尾小、后脚高、金褐毛色构成组合，不由单项推出威豪。 |
| 8 爪 | 爪贵藏，又贵油爪；“爪露能翻瓦”；“油爪滑生光” | 既有藏爪为佳，也记露爪翻瓦，保留文本张力。陶文伯炳文夹注以行地留下爪痕解释“油爪”，称上品；不能只解释成爪子油亮。旧“小露”订为“爪露”。 |
| 9 尾 | 尾贵长、细、尖，尾节贵短，又贵常摆；“尾长节短多伶俐”；“尾大懒如蛇”；“坐立尾常摆，虽睡鼠亦亡” | 长细尖、节短、常摆分别列清。识典转录“伶例”，此处释为伶俐，并非已核原刻字形。黄汉以尾掉风解释威势并反对截尾；余文竹引虎竖尾作帆是后出补证。 |
| 10 声 | 声贵喊，喊是猛；“眼带金光身要短，面要虎威声要喊” | 金光眼、短身、虎威面、猛声是组合。黄汉解“好猫不做声”为平时不叫而出声猛烈，不是永远无声。 |
| 11 口腔坎 | 猫口贵有坎，九坎上、七坎次；“上腭生九坎，周年断鼠声。七坎捉三季，坎少养不成” | 以坎数附会全年或三季捕鼠。夹注另标并见《挥尘新谈》《山堂肆考》（前一书名照识典转录，疑字待原刻核）。姚百征的雄九七五、雌八六四另见第七节，非这条原句。 |
| 12 睡姿 | 睡要蟠而圆，藏头而棹尾；“身屈神固，一枪自护” | 蜷圆、藏头、尾动联系神定自护。识典作“棹尾”，旧笔记“掉尾”为释义，不再混称逐字原文。 |

### 十二要之外：五长、五秃

黄汉按语另引、并明确标“见《相猫经》”：头、尾、身、足、耳全长为“五长”，名“蛇相”，也被评为良；五者皆短为“五秃”，说能镇三五家。这是十二要以外的补充，不是第十三要；它与单项偏爱圆头、短腰、小耳的标准并存，不能强行合成无例外规则。紧接的王玥亭猫来往三处、鼠耗皆绝，是黄汉举例的故事，并非追加一项形相。

## 六、毛色、纹样与相关禁忌：完整分层索引

据[识典卷上“毛色”全门](https://www.shidianguji.com/zh/book/CADAL02035808/chapter/1l7l4yva9iyhy)核对。以下 A 项是明确标《相猫经》的内容；B 项是同门其他来源，详解归《猫苑》总结，避免把全门都冒充《相猫经》。

### 6.1 A：明确归名《相猫经》的色相

| 名称／规则 | 形色条件 | 原载评价或命名说明 |
|---|---|---|
| 纯色、驳色次序 | 纯黄、纯白、纯黑；纯狸色也有佳者；驳色中乌云盖雪、玳瑁斑、狸而驳 | 次序黄、白、黑，重“色之纯”；杂色以乌云盖雪上、玳瑁斑次、狸而驳下。仅为古代等级。 |
| 四时好 | 纯黄、纯白或纯黑 | “凡纯色无论黄白黑，皆名四时好”；夹注明标《相猫经》。 |
| 金丝褐 | 褐色带金丝 | “金丝褐色最威豪”归《相猫经》；“褐”为黄黑相兼的解释是黄汉按语。 |
| 玳瑁斑 | 黄、白、黑三色相兼 | 古书称三色为玳瑁斑；不直接套现代玳瑁与三花的划分。 |
| 乌云盖雪 | 背黑，肚、腿、蹄爪都白 | 必须满足原文分布，不能只凭黑白二色命名。 |
| 踏雪寻梅 | 仅四蹄白；纯黄白爪也同名 | 原文另有“其纯黄白爪者同”，旧总结漏掉了黄色主体。 |
| 雪里拖枪 | 通身白、尾独黑 | 原说最吉，并附“黑尾之猫通身白，人家畜之产豪杰”。 |
| 垂珠 | 通身黑，尾尖一点白 | 只有命名，不增补未载的财运断语。 |
| 挂印拖枪／印星猫 | 白身、纯黑尾，额上一团黑 | 原说主贵；口诀作“白额过腰通到尾，正中一点是圆星”。以明确散文条件为匹配依据，不反用语义不明的口诀臆造花纹。 |
| 银枪插铁瓶 | 纯黑身、白尾 | 识典为“插”（揷），旧“拖”订正。 |
| 绣虎 | 白身有黄点 | 古典点色名。 |
| 梅花豹／金钱梅花 | 黑身有白点 | 识典有“自点”疑识误，按上下文释白点，保留校核边界。 |
| 金被银床 | 黄身白肚 | 只用明确的身腹配色。 |
| 金簪插银瓶 | 通身白，尾独黄 | 与“金索挂银瓶”的地方俗称分层。 |
| 将军挂印 | 通身黑或白，背上一点黄毛 | 页面正文和夹注把书名分成“相，猫经”，合读为《相猫经》；不缩成任意背部斑点。 |

### 6.2 A：旋毛、排泄相关原断语

- **胸部旋毛**：“胸有旋毛，猫命不长”；另有左旋被说成犯狗、右旋被说成水伤，通身有旋被说成凶折多殃。各条件和方向分别保留，不能只概括为“旋毛不好”，也不能当真实寿命预测。
- **肛门周围生毛**：“毛生屎窟，屙屎满屋，非佳猫也”。本页所说为“屎”，旧总结“尿窟／屙尿”改正。古书没有提供现代解剖阈值，不可据普通肛周毛判个体好坏。

### 6.3 B：相邻但不属于《相猫经》原句的材料

详见[《猫苑》“相法补全”](猫苑.md)：黄汉称纯黄金丝、纯黑铁色；陶文伯的负印拖枪；黄汉转《表异录》的衔蝉奴；诸缉山的金索挂银瓶；《致富奇书》的缠得过；《相畜余编》的拦截纹、寿纹、紫色虎纹；《崇正辟谬通书》（识典夹注有疑字）的花朝口；卷下丁仲文的按色雅号、郑荻畴《猫格》及诗文行为品评也另属《猫苑》补说。**尤其拦截纹和寿纹确为相法，但不能标成《相猫经》十二要或原口诀。**

## 七、相猫、选猫、纳猫与验猫方法

### 7.1 相猫与选猫：文献内部的操作顺序

1. **先看十二要**：头面至睡姿逐项看形态，尤其是眼、鼻、须、腰、脚、爪、尾和上腭“坎”。
2. **再看毛色和纹样**：先辨纯色与驳色，再看乌云盖雪、雪里拖枪、印星等特殊斑纹。这里的“上品”是历史品相。
3. **以实际用途校验**：口诀反复以“断鼠、捕鼠、鼠亡”为最高功能目标；若出现“鸡鸭一网收”，则反而提示可能扰食家禽。真正选择时不能只凭毛色吉名，应观察是否能守家、捕鼠、少扰人畜；这是对文本功能目标的概括，不是《相猫经》声称的现代测试法。
4. **区分相法与故事**：例如《猫苑》记王玥亭所得猫能在三处住所往来而使各处鼠耗皆绝，这是后出的个案故事，不是普遍保证。

### 7.2 《猫苑》所记“验猫法”（明确是后出按语/地方说）

- 黄汉按语记“粤人验猫法”：提起猫耳时，四脚与尾随即缩上，便认为优；否则庸劣。
- 同一按语又记湘潭张博斋说：把猫掷向墙壁，四爪能抓住墙而不脱，为最上品。

两法的出处在《猫苑》条文中是明确的，但都不是《相猫经》十二要原文；它们是清代地方验猫传闻，且后者可能伤害动物，本文仅作史料转录，**不建议模仿**。此外，《猫苑》卷上“灵异”末记嘉应相猫者张七以眼色、颈骨宽度、爪气等判断捕鼠和寿长，也属于后出的个人经验，不应升格为《相猫经》规则。

### 7.3 《猫苑》所记“纳猫法”

《猫苑》卷下引《崇正辟谬通书》载一套纳猫仪式：用斗或桶和布袋装猫带回；路遇沟缺填石，使猫“不过家”，从吉方回；到家后拜堂、灶、犬；把箸横插土堆（黄汉按说瓯人以草代箸并量猫尾长短），祈使猫不在家撒屎，再让猫上床睡以免逃走。该书还列纳猫宜日及忌日。

这是真有出处的**纳猫习俗**，不是《相猫经》的相貌口诀，也不是可验证的防逃、定居方法。另有“古人乞猫必用聘”之说，条中引黄山谷“买鱼穿柳聘衔蝉”、陆游“裹盐迎得小狸奴”；《猫苑》又记录潮人以糖、绍兴人以苎麻等地方聘猫礼。这些材料说明纳猫兼有交换礼俗和祈愿意味，不应解释为猫的生理需要。

## 八、代表性原文（短引）

以下短引以通行简体及释读字转写，非原刻外交式录文，均来自《猫苑》“形相”“毛色”条，统一注明出处为“《猫苑》所录《相猫经》”：

- **总纲**：“猫之相有十二要。”
- **面相**：“头面贵圆。”
- **眼与鼻**：“眼贵金银色”；“鼻贵平直，宜干。”
- **须与尾**：“须劲虎威多”；“尾长节短多伶俐。”
- **声音**：“声贵喊，夫喊，猛之谓也。”
- **上腭**：“九坎为上，七坎次之。”
- **睡姿**：“睡要蟠而圆，藏头而棹尾。”
- **毛色**：“纯黄为上，纯白次之，纯黑又次之。”
- **鼠用**：“坐立尾常摆，虽睡鼠亦亡。”
- **纹色**：“黑尾之猫通身白，人家畜之产豪杰。”

其中“金眼夜明灯”“乌龙入眼懒如蛇”“面长鼻梁钩，鸡鸭一网收”等也是《猫苑》以“经云”引出的短句；由于其断语性质很强，引用时应连同“传统相法”语境，不得改写为科学事实。

## 九、史料性质与局限

1. **辑录而非原书校本**：黄汉自序、凡例都说明《猫苑》是广搜群籍、笔记、传闻的辑书；《相猫经》原书的卷次、作者、时代、版本系统均未在现存材料中交代。今天读到的是后世选录，不能据此恢复原貌。
2. **层次混杂**：同一条中可能先录“经云”，后接“汉按”、友人亲见、地方俗说。比如“油爪”的解释、提耳验猫、掷墙验猫，均是《猫苑》附记；引用时必须注明层级。
3. **内容混合经验与占验**：捕鼠、会否扰鸡鸭、是否恋家等有实际生活背景；九坎定捕鼠年限、毛色主富贵、纹样主豪杰则带占验和象征。二者不能以同样证据标准阅读。
4. **没有现代品种和统计**：所谓狮猫、无尾猫、麒麟尾、金丝等是历史称谓或外观类别；没有血统登记、样本数、地域边界和实验数据，不能直接映射现代品种，更不能由毛色、眼色推定性格、寿命或捕鼠能力。
5. **部分字句语义不稳**：“面长鸡种绝”“腰长会过家”“坎少养不成”等短语的具体解释依赖古代语境；本文保留原句并只作谨慎释义，不强行补造失传的口诀。
6. **动物伦理与现代养护**：清代验猫方式（特别是掷墙）可能造成伤害，纳猫术也含占日、祈愿；它们只可作为历史材料，不能作为现代领养和照护指南。现代选猫应依据健康检查、性格观察和适当的行为评估。
