# 0001 · 相猫海报改为三源内容、直写品种、无免责、去装饰

`cat-physiognomy` 原设计把海报限制为“古籍趣味解读”：品种只写“外观似 ××／仅凭照片推测”，纸片只引四书说法，底部印来源与“古籍趣味解读，仅供娱乐”，画面允许印章、书法体等古风装饰，且同一特征可在品种栏与相猫栏重复出现。用户明确要求扩展与放开：相猫不限于古籍，现代品种标准与猫习性研究（CFA/TICA、Salonen 2019、Feline Five、环境丰容等）也进知识库；品种以防盗扣标签直写中文市场通名，允许写错；海报可含完全无依据的趣味脑洞（“前世可能是亚历山大三世的爱猫”）；画面去标题、去底部说明行，去印章/古风字体等一切附加图形，文字统一为现代黑体撕纸纸片并全文去重。

决定：海报内容走三源混合——古籍条目、现代观察与通识、趣味脑洞，画面上不标整行来源；保留四条硬边界：负面古断（凶/败家/寿夭）整类跳过、医疗/喂养/品相鉴定类不写、冒犯内容不写、“研究表明／专家说”科学腔句式禁用（脑洞不借科学外衣）；免责只在聊天回执出现。视觉重做为满幅做旧米黄纸底、中央照片撕纸剪贴、防盗扣标签、撕纸纸片黑体。后续细则（用户出图后反馈）：防盗扣改为穿过猫剪贴纸面而非贴于身上；画面禁止空白/无字纸片与正文分号；纸片句式要求变化不雷同；有明确出处的条目允许“——《相猫经》”式出处小注（无依据条目不加）。第二轮反馈：出处小注同一海报同一书名至多一次、宁可只标一两处也不条条都注《相猫经》；文案以命理断语口吻为主（特征只当引子，落点是运势/福气/际遇，可夸张、说错无妨），不写复述外观的描述句。

理由：这是宠物趣味海报而非相术咨询，用户偏好“好玩优先”；严谨限定语会压低脑洞密度。取舍与代价：品种可能写错（用户接受，错判本身是笑点成本）；画面不设整行来源——有出处的条目用“——《书名》”小注，其余由回执一句话承担核对职责；与 human-physiognomy 的免责文化刻意不同——猫海报不承担性格/健康/品相结论。被否方案：保留古籍+免责路线（与“纯娱乐、错了没事”冲突）、每张纸片强制标注来源（破坏画面，最终改为可选小注）。若平台或合规将来需要，免责可只加在回执而不回画面。
